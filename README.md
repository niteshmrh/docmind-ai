# DocMind AI

Enterprise AI Document Intelligence Platform powered by Local LLMs and OpenAI.

---

## 🚀 Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- Shadcn UI

### Backend

- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Multer

### AI

- Ollama (Local Development)
- OpenAI (Production)
- RAG Pipeline
- Vector Search

### Infrastructure

- Docker
- Docker Compose
